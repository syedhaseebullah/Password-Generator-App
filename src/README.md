# Password Generator

A clean, responsive, and secure Password Generator web application built with **React.js** and **Tailwind CSS**.

## Features

- **Custom Length Control**: Dynamically adjust password length (8 to 100 characters) using an interactive range slider.
- **Configurable Rules**: Toggle options to include numbers and special characters.
- **One-Click Copy**: Fast clipboard functionality powered by React `useRef`.
- **Responsive Design**: Fully mobile-friendly UI styled using Tailwind CSS.

## Tech Stack

- **Framework**: React.js (Vite)
- **Styling**: Tailwind CSS
- **Hooks Used**: `useState`, `useCallback`, `useEffect`, `useRef`
